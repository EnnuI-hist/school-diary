# Веб-приложение «Дневник успеваемости» (10 класс)

Одностраничное веб-приложение (SPA) на чистом HTML5, CSS3 и Vanilla JavaScript для учета успеваемости и посещаемости десятиклассников в условиях семестровой системы обучения. Приложение работает полностью автономно в браузере с автосохранением в `localStorage`, поддерживает экспорт/импорт данных в JSON и готово к публикации на **GitHub Pages**.

```text
├── .nojekyll        # Флаг для корректной раздачи статических файлов на GitHub Pages
└── README.md        # Руководство по проекту и деплою
```

## ✨ Реализованный функционал

### 1. Учебный календарь 2026–2027 (по умолчанию)
- **Учебная пятидневка:** занятия с понедельника по пятницу. Суббота и воскресенье — выходные дни.
- **1-й семестр:** с `01.09.2026` по `30.12.2026`
- **2-й семестр:** с `11.01.2027` по `28.05.2027`
- **Каникулы и праздники (автоматически исключаются из учебных дней):**
  1. Осенние каникулы: `26.10.2026 — 04.11.2026`
  2. Зимние каникулы: `31.12.2026 — 10.01.2027`
  3. Весенние каникулы: `27.03.2027 — 04.04.2027`

### 2. Расписание 10 класса (Пн–Пт)
- **Понедельник:** 1. ОБЗР, 2. Обществознание, 3. Алгебра, 4. История, 5. Проект, 6. Право, 7. Физика, 8. Разговоры о важном
- **Вторник:** 1. Иностранный язык, 2. Русский язык, 3. Литература, 4. Алгебра, 5. География, 6. Геометрия, 7. Обществознание
- **Среда:** 1. Русский язык, 2. Физика, 3. Литература, 4. Биология, 5. Алгебра, 6. Литература, 7. Иностранный язык
- **Четверг:** Приход ко 2-му уроку (1-й урок отсутствует, не считается за прогул): 2. Физкультура, 3. Обществознание, 4. Информатика, 5. История, 6. Алгебра, 7. Электив по русскому языку, 8. Классный час
- **Пятница:** 1. Иностранный язык, 2. Химия, 3. Обществознание, 4. Геометрия, 5. Физкультура, 6. Геометрия, 7. Вероятность и статистика
- **Суббота:** Выходной день (нет запланированных уроков).

### 3. Вкладка «Дневник»
- **Удобная навигация:**
  - Кнопки **«← Пред. неделя»**, **«Текущая неделя (Сегодня)»**, **«След. неделя →»**.
  - Быстрый переход по месяцам и семестрам.
  - Календарный выбор даты (`input type="date"`).
- **Сетка дней (Понедельник — Суббота):**
  - Подсветка текущего дня (**«Сегодня»**).
  - Быстрые кнопки массовой отметки дня: **«Н на весь день»**, **«У на весь день»**, **«Сброс (Был)»**.
  - **Разовые выходные и праздники в 1 клик (`🏖 Выходной` / `↩️ Вернуть учебный день`):**
    - Кнопка `🏖 Выходной` в шапке карточки любого учебного дня позволяет моментально объявить разовый выходной, праздник или день олимпиады.
    - Карточка приглушается (`is-holiday`), сетка уроков скрывается, появляется статус-бейдж `Выходной / Праздник` и информационная плашка об отмене занятий.
    - Возможность добавлять и просматривать заметки на день (`📝 Заметка`) полностью сохраняется.
    - Кнопка `↩️ Вернуть учебный день` возвращает уроки и нормальный учебный статус в один клик.
    - Все разовые выходные автоматически и полностью исключаются из аналитики во вкладке «Статистика» (не учитываются в общем плане уроков, не считаются пропусками и не уменьшают запас прочности).
- **Текстовые заметки на весь день (`📝 Заметка`):**
  - Компактная кнопка `+ Заметка` в шапке карточки каждого дня.
  - При отсутствии заметки карточка остается компактной и минималистичной.
  - Встроенный редактор с автовысотой, поддержкой многострочного ввода (`Enter`) для списков задач, Д/З или напоминаний.
  - Автосохранение при вводе и смене фокуса (`input`/`blur`), выход по клавише `Esc` или кнопке «Готово».
  - Отображение сохраненной заметки в аккуратном блоке с золотистым акцентом, быстрым кликом для редактирования и кнопкой удаления.
- **Интерактивные уроки:**
  - Сегментированный переключатель посещаемости `[ Был | Н | У ]` с цветной подсветкой.
  - Быстрое выставление оценок: кнопки `+ Оценка: [ 5 ] [ 4 ] [ 3 ] [ 2 ]`.
  - Цветные бейджи оценок: `5` (зеленый), `4` (голубой), `3` (янтарный), `2` (розовый).
  - Удаление оценки по клику на бейдж.

### 4. Вкладка «Статистика»
- **Фильтрация периода и режима:**
  - Переключатель периода: **«1-й семестр»**, **«2-й семестр»**, **«Весь учебный год»**.
  - Переключатель базы расчета:
    - **«На текущий день (прошедшие)»** — процент прогулов считается только от уроков, прошедших до сегодняшнего дня.
    - **«За весь период (план)»** — процент прогулов от общего плана уроков.
- **Верхний дашборд:** всего уроков, прогулы («Н»), уважительные пропуски («У»), общий процент непосещаемости и число прогулянных дней.
- **Аналитика успеваемости и посещаемости по предметам:**
  - Средний балл (напр. `4.33`) и прогнозируемая итоговая оценка ($\ge 4.50 \implies 5$, $\ge 3.50 \implies 4$ и т.д.).
  - **Умный калькулятор «До цели»:** рассчитывает точное количество пятерок (или четверок) подряд, чтобы выйти на желаемый итоговый балл.
  - **Контроль риска неаттестации и запас прочности:**
    - Настраиваемый порог предупреждения по неуважительным пропускам (`Н`), по умолчанию **50%** (превентивный запас).
    - **Умный счетчик запаса прочности по прогулам:** динамический расчет количества уроков по предмету, которые еще можно пропустить со статусом «Н» до достижения порога риска.
    - Цветовые статусы запаса: `🟢 Можно еще скипнуть: X уроков (из Y допустимых)`, `🟡 Запас исчерпан: 0 уроков (следующий прогул превысит порог)`, `🔴 Лимит превышен на X уроков`.
    - Красная предупреждающая плашка `⚠️ Риск неаттестации: X% прогулов (установленный порог — 50%)` и красная рамка карточки при $\ge 50\%$.
    - Мягкая желтая подсказка `⚡ Приближение к порогу: X% прогулов (лимит — 50%)` и желтая рамка за 10% до порога (от 40% до 49.9%).

### 5. Вкладка «Настройки» и резервная копия
- Настройка дат семестров и каникул.
- Управление предметами и расписанием недели.
- **Контроль посещаемости:** настройка порога прогулов для предупреждения от 10% до 100% (по умолчанию 50%).
- **«Скачать JSON»** / **«Загрузить JSON»** — полный экспорт и импорт всех настроек, разовых выходных (`customHolidays`), порога прогулов, заметок на дни, оценок и посещаемости.
- **Версионирование схемы (`configVersion: 2`):** автоматическая миграция со старых демонстрационных конфигов без потери выставленных пользователем оценок и заметок.
