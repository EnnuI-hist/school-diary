# Веб-приложение «Дневник успеваемости» (10 класс)

Одностраничное веб-приложение (SPA) на чистом HTML5, CSS3 и Vanilla JavaScript для учета успеваемости и посещаемости десятиклассников в условиях семестровой системы обучения. Приложение работает полностью автономно в браузере с автосохранением в `localStorage`, поддерживает экспорт/импорт данных в JSON и готово к публикации на **GitHub Pages**.

---


## ✨ Реализованный функционал

### 1. Вкладка «Дневник»
- **Динамическая генерация учебного года:**
  - Автоматически рассчитывает учебные дни на основе диапазонов 1-го и 2-го семестров из Настроек.
  - Исключает воскресенья и периоды каникул/праздников.
  - Дни каникул отображаются приглушенными карточками с бейджем и названием праздника/каникул.
  - При изменении шаблона расписания или дат каникул выставленные ранее оценки и статусы посещаемости за конкретные даты (`YYYY-MM-DD`) сохраняются в истории.
- **Удобная навигация:**
  - Кнопки **«← Пред. неделя»**, **«Текущая неделя (Сегодня)»**, **«След. неделя →»**.
  - Отображение диапазона дат недели с бейджем семестра (*«1-й семестр»* / *«2-й семестр»*).
  - Быстрый прыжок по месяцам учебного года и прямой выбор даты в календаре.
- **Сетка дней (Понедельник — Суббота):**
  - Подсветка текущего дня (**«Сегодня»**).
  - Быстрые кнопки массовой отметки дня:
    - **«Н на весь день»** — прогул на все уроки дня.
    - **«У на весь день»** — уважительная причина на все уроки дня.
    - **«Сброс (Был)»** — возвращает статус присутствия.
- **Интерактивные уроки:**
  - Сегментированный переключатель посещаемости `[ Был | Н | У ]` с цветной подсветкой.
  - Быстрое выставление оценок: кнопки `+ Оценка: [ 5 ] [ 4 ] [ 3 ] [ 2 ]`.
  - Цветные бейджи оценок: `5` (зеленый), `4` (голубой), `3` (янтарный), `2` (розовый).
  - Удаление оценки по клику на бейдж.

### 2. Вкладка «Статистика»
- **Фильтрация периода и режима:**
  - Переключатель периода: **«1-й семестр»**, **«2-й семестр»**, **«Весь учебный год»** (по умолчанию активируется текущий семестр).
  - Переключатель базы расчета:
    - **«На текущий день (прошедшие)»** — процент прогулов считается только от уроков, которые уже прошли с начала семестра до сегодняшнего дня.
    - **«За весь период (план)»** — процент прогулов считается от общего количества уроков за весь семестр/год.
  - Информационная плашка с точным числом пройденных и запланированных уроков.
- **Верхний дашборд (4 ключевые метрики):**
  1. **Всего уроков:** число уроков по расписанию (без каникул и воскресений).
  2. **Неуважительные прогулы («Н»):** количество уроков со статусом «Н» и процент от уроков (красный акцент).
  3. **Уважительные пропуски («У»):** количество уроков со статусом «У» и процент от уроков (синий акцент).
  4. **Общий процент пропусков (Н + У):** суммарный процент непосещаемости + количество полностью прогулянных дней.
- **Аналитика успеваемости и посещаемости по предметам:**
  - Список всех оценок по предмету за выбранный период.
  - **Средний балл** (с точностью до сотых, напр. `4.33`) и **прогнозируемая итоговая оценка**:
    - $\ge 4.50 \implies 5$ (зеленый бейдж)
    - $\ge 3.50 \implies 4$ (синий бейдж)
    - $\ge 2.50 \implies 3$ (янтарный бейдж)
    - $< 2.50 \implies 2$ (розовый бейдж)
  - **Умный калькулятор «До цели»:**
    - Для среднего балла от `3.50` до `4.50`: рассчитывает, сколько именно оценок `5` нужно получить подряд, чтобы достичь `4.50` (напр. *«До «5» нужно: 3 × «5» без других отметок»*).
    - Для среднего балла ниже `3.50`: рассчитывает необходимое количество оценок `5` или `4`, чтобы выйти на `3.50` и не допустить тройку или н/а.
    - Для отличников: поздравление *«Цель достигнута: отлично (5) ⭐»*.
  - **Посещаемость по предмету:**
    - Количество уроков, пропусков `Н` и `У`, процент непосещаемости.
    - Наглядный двухцветный прогресс-бар пропусков.
    - **Контроль риска неаттестации:** если процент неуважительных прогулов `Н` превышает **25–30%**, карточка подсвечивается предупреждающей рамкой и появляется плашка *«⚠️ Риск неаттестации: X% прогулов»*.

### 3. Вкладка «Настройки»
- **Даты семестров:** даты начала и окончания 1-го и 2-го семестров с мгновенным автосохранением.
- **Каникулы и праздники:** добавление именованных периодов каникул с проверкой дат и удаление.
- **Расписание недели:**
  - Управление списком предметов (добавление, удаление тегов).
  - Сетка дней (Пн–Сб) для настройки уроков из выпадающих списков.
- **Резервная копия:**
  - **«Скачать JSON»** — полный экспорт настроек, дат, расписания, всех оценок и посещаемости в один файл.
  - **«Загрузить JSON»** — безопасный импорт с валидацией структуры и обновлением всех вкладок.
  - **«Сбросить к базовым»** — сброс к первоначальному состоянию.

## 🚀 Деплой на GitHub Pages

1. Инициализируйте репозиторий в папке проекта:
   ```bash
   git init
   git add .
   git commit -m "feat: complete diary, statistics and settings for 10th grade diary"
   ```
2. Создайте новый репозиторий на [GitHub](https://github.com/new).
3. Привяжите удаленный репозиторий и отправьте код:
   ```bash
   git remote add origin https://github.com/<ваш_логин>/<имя_репозитория>.git
   git branch -M main
   git push -u origin main
   ```
4. В репозитории на GitHub перейдите в:
   **Settings** ➔ **Pages** ➔ в секции **Build and deployment** выберите:
   - **Source:** `Deploy from a branch`
   - **Branch:** `main` / folder: `/ (root)`
   - Нажмите **Save**.
5. Приложение станет доступно по адресу `https://<ваш_логин>.github.io/<имя_репозитория>/`.
